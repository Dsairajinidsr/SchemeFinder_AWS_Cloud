# SchemeFinder – AI-Powered Government Scheme Eligibility & Recommendation System

## 📌 About the Project

SchemeFinder is an AI-powered platform designed to help citizens discover government welfare schemes based on their eligibility. It aims to simplify access to scheme information by using document processing, eligibility checking, and personalized recommendations.

## 📝 Abstract

Government welfare schemes play an important role in social development. However, many citizens are unable to benefit from these schemes due to limited awareness, scattered information, and complex eligibility criteria.

SchemeFinder proposes a centralized, cloud-based platform that helps users discover relevant government schemes by analyzing submitted information and documents. Using technologies such as Optical Character Recognition (OCR), an eligibility-checking system, and an AI-based recommendation engine, the platform aims to make scheme discovery simpler, faster, and more accessible.

## 🎯 Problem Statement

Information about government welfare schemes is distributed across multiple platforms. Understanding eligibility conditions and identifying suitable schemes can be difficult and time-consuming. As a result, eligible citizens may miss benefits available to them.

## 💡 Proposed Solution

SchemeFinder aims to provide a unified platform that organizes government scheme information, extracts relevant information from uploaded documents, checks eligibility criteria, and recommends potentially suitable schemes. It is designed to improve accessibility, transparency, and ease of use.

## 🎯 Objectives

- Provide a centralized platform for discovering government schemes.
- Simplify eligibility checking.
- Use document processing to reduce manual data entry.
- Recommend schemes based on user-provided information.
- Improve transparency and accessibility of scheme information.

## ✨ Key Features

- **Government Scheme Discovery:** Explore available welfare schemes.
- **Document Processing:** Extract relevant information from uploaded documents using OCR.
- **Eligibility Checking:** Compare user information against scheme requirements.
- **Scheme Recommendations:** Identify potentially relevant schemes.
- **AI Chatbot:** Help users understand scheme details and eligibility requirements.
- **Cloud-Based Architecture:** Support secure and accessible application deployment.

## 🔄 System Workflow

1. The user accesses the SchemeFinder platform.
2. The user provides relevant information or uploads supported documents.
3. The system extracts information using OCR, where applicable.
4. The eligibility engine evaluates the available information against scheme criteria.
5. The recommendation engine displays potentially suitable schemes.
6. The user reviews scheme details and verifies requirements through official sources.
